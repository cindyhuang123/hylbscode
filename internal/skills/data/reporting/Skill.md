# 报告撰写

**先问清读者是谁、用途是什么，再动笔；结构清晰优先于辞藻。**

## 准备
1. 用 SearchHistory / Grep 收集相关背景与上次结论，别凭空写。

## Procedure
2. 先交互确认 3 件事：报告对象 / 篇幅 / 是否要含数据。
3. 输出用固定 markdown 结构（见下方模板）。
4. 数据/事实要标来源；不确定的标注"待确认"，不要编造数字。
5. 开头给一页 TL;DR 结论，细节放后。

## 输出模板
```markdown
# <报告标题>  (YYYY-MM-DD)

## 摘要（3-5 条结论）
- 

## 背景
## 现状分析
## 结论与建议
## 附录 / 数据来源
```

## 禁止
- 不写空话套话；结论要可执行。
