# 计划制定

**先定目标与约束，再拆任务，最后排优先级；SMART 原则。**

## Procedure
1. 澄清：目标是什么、截止时间、范围边界、可用的 Todo 工具（本项目有 TodoTool 内建跟踪）。
2. 拆解为可独立完成的子任务（一事一条可验收）。
3. 标注依赖关系（哪些要等哪些）、风险（高/中/低）。
4. 排优先级（重要紧急矩阵），明确里程碑 M1/M2/...
5. 用本项目的 Todo 工具落地为可勾选清单，供执行时逐个 mark 完成。

## 输出模板
```markdown
# <计划名称> (YYYY-MM-DD)

## 目标（SMART）
## 约束与假设
## 任务清单
| 任务 | 优先级 | 依赖 | 状态 ([ ]/[x]) |
## 里程碑
## 风险与应对
## 会议议程（如适用）
```

## 禁止
- 不排假优先级；每项任务必须有验收标准。
