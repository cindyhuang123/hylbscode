# 汇报与演讲

**结论先行，一页一个观点；听众时间有限，先讲最重要的。**

## 准备
1. 先确认 3 件事：听众是谁（决定深度与用词）、时长多少、目的是什么（告知/说服/决策/动员）。
2. 用 SearchHistory / Grep 收集支撑数据与事实，任何数字都要有来源。

## Procedure
3. 用金字塔结构搭故事线：结论 → 3 个支撑论点 → 论据/数据 → 行动号召。
4. 常见故事线（选一）：现状-痛点-方案-收益；过去-现在-未来；问题-原因-对策。
5. 每页只讲一个观点，先给页面标题式的结论句，再展开。
6. 收尾明确"要听众做什么"（拍板、预算、排期、只是知悉）。

## 输出模板
```markdown
# <主题> 汇报/演讲 (时长: X 分钟)

## 开场 30 秒：一句话结论
## 论点 1 / 论据
## 论点 2 / 论据
## 论点 3 / 论据
## 风险与反问预案（提前列 3 个会被问的问题）
## 结尾：行动号召
```

## 禁止
- 不堆砌数据不做解读；数据必须配"所以呢"。
- 不把 PPT 当文档写，页面文字要少。
