# 快速学习

**先跑通最小闭环建立正反馈，再横向铺开；不要上来就啃大部头。**

## Procedure
1. 先画"地图"：官方文档 Quickstart + 一个口碑教程，只读前 1-2 章即可开始。
2. 立一个 30 分钟能见成果的最小目标（跑通 Hello World / 最小示例 / 一页笔记）。
3. 按 3 步循环推进：照抄官方示例 → 自己改参数/变量（观察变化） → 脱离示例自己写。
4. 遇到报错先记错误信息再搜，报错本身就是最准的学习材料。
5. 学完用费曼法输出：写 3 条"一句话总结 + 一个例子"，能讲清才算会。
6. 对照旧知识迁移：新东西和我会的什么最像？差异点单独记忆。

## 输出模板
```markdown
# <主题> 学习记录

## 最小闭环目标（今天能跑通的）
## 照抄 → 改 → 自己写 三遍记录
## 踩的坑（报错 + 解法）
## 3 条一句话总结（附例子）
## 与已有知识的关系 / 差异点
```

## 禁止
- 不花超过 1/3 的时间在"收集资料"上，动手优先。
- 不追求一次看懂全部，先窄后宽。
