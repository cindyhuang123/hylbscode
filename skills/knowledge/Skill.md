# 知识管理

**能用自己的话讲出来才算学会；复盘的产出必须是"下次改什么"。**

## 笔记
1. 原子化：一个主题一条笔记，标题即结论或问题。
2. 记录"为什么"（背景与决策依据），不只记"怎么做"。
3. 用费曼法自检：把笔记用大白话讲给外行听，讲不通的地方就是没懂。

## 复盘（个人/项目）
4. 三个问题：**做对了什么**（保留）、**做错了什么**（改）、**下次要试什么**。
5. 复盘要落到可执行动作，写进 Todo 工具，否则等于没复盘。

## 沉淀
6. 通用经验写成模板/清单/可复用片段，放进对应技能或文档，避免重复踩坑。

## 输出模板
```markdown
# <主题> 复盘/笔记 (YYYY-MM-DD)

## 背景与当初的目标
## 做对了什么（保留）
## 做错了/没做好的（改进）
## 关键教训（一句话版本）
## 下次行动清单
```

## 禁止
- 不复盘情绪，只复盘事实与决策；对事不对人。
- 不把笔记写成流水账，每篇要有结论。
