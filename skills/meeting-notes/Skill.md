# 会议纪要

**纪要的价值在行动项：谁、在何时前、做什么；结论不清的会议等于白开。**

## 会前
1. 提前收集议程（议题清单），明确每个议题的决策人或负责人。

## 会中
2. 按议题记录：背景一句 → 讨论要点 → **结论** → 行动项。
3. 每个行动项必须有：负责人、截止时间、可验收的结果；没有责任人就没有行动项。

## 会后
4. 输出结构化纪要并分发，标注"决策"与"待确认"分开列。

## 输出模板
```markdown
# <会议名> 纪要 (YYYY-MM-DD)

## 参会人 / 议程
## 议题一：<标题>
- 结论：
- 行动项：
  | 事项 | 负责人 | 截止 | 状态 |
## 待确认事项（悬而未决，写明卡点）
```

## 禁止
- 不把会议全程录音式还原；只留结论和行动项。
- 不遗漏"待确认"事项——它们是下次会议的输入。
