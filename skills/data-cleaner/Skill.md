# 数据清洗

**先看样本写脚本，批量操作一律 python3 脚本化，绝不覆盖原文件。**

## Procedure
1. 看样本：View 前 20~50 行，确认分隔符、编码、字段名、缺失值表示（空串 / NA / null）。
2. 定规则：与用户确认操作清单（去重键、空值策略、日期格式、大小写统一等），有歧义先问。
3. 写脚本：python3 标准库（`csv` / `json`）优先；确需 Excel 时用 `pandas` + `openpyxl`。脚本放 /tmp 或项目 tmp 目录。
4. 干跑统计：先输出"将删除 N 行 / 修改 M 字段 / 重命名 K 列"的统计，与用户预期一致再写入。
5. 结果：输出到新文件（如 `xxx.cleaned.csv`），保留原文件；报告去重前后行数对比。

## 禁止
- 不许直接覆盖原数据文件；必须先输出到新文件。
- 不许手工逐行编辑大数据；批量改动必须脚本化并可复跑。
- 不许静默丢弃数据；每一类删除都要给出计数与样例。
