# 决策分析

**决策的质量取决于标准和信息，不取决于拍脑袋；记录假设以便日后复盘。**

## Procedure
1. 先写清楚决策问题：要解决什么、决策时点、谁决策、何时必须出结论。
2. 列出决策标准并加权（成本/时间/风险/长期收益…），标准不重叠。
3. 候选方案逐个对照打分，分数必须能说出依据，不能凭感觉填。
4. 显式列出每个方案的代价与退出成本（选错了能不能回头、代价多大）。
5. 做不确定的决策时，明确关键假设与"如果假设错了怎么办"（找反证）。
6. 记录决策日志：当时的信息、假设、选择、理由——这是复盘的地基。

## 输出模板
```markdown
# <决策主题> 决策记录 (YYYY-MM-DD)

## 决策问题与约束
## 决策标准（权重）
## 候选方案对比（打分表 + 依据）
## 代价与退出成本
## 关键假设（含反证）
## 最终决策与理由
```

## 禁止
- 不允许"五五开"式结论：不选也是一种决策，也要记录理由。
- 不为了赶时点省略标准打分。
