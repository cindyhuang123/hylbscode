# 调查方法论

**多源交叉验证，先广后深，结论必须给证据链。**

## Procedure
1. 明确调查问题和范围（是什么 / 为什么 / 选哪个）。
2. 先 Sourcegraph / 网络泛搜收集候选，再逐个深入。
3. 每个结论记录来源；能查一手的（官方文档、源码）优先于二手。
4. 用 Grep / Ls 探查本仓库已用到的相关技术栈，避免"船上补票"式的冲突选型。
5. 最后输出对比表 + 明确推荐 + 理由 + 代价。

## 输出模板
```markdown
# <调研主题> 调查

## 调查问题
## 候选方案（对比表：维度×方案 打分）
## 关键证据/来源（逐条）
## 推荐结论
## 风险与代价（不推荐项也列出）
```

## 禁止
- 不许只给单一来源；结论必须能回溯。
